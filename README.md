# AWS EC2 Static Website Deployment

## Project URL

https://roadmap.sh/projects/ec2-instance

## Description

This project demonstrates how to deploy a static website on an AWS EC2 instance using Ubuntu and Nginx.

## Steps Performed

- Launched Ubuntu EC2 Instance
- Connected using SSH
- Updated packages
- Installed Nginx
- Created index.html
- Deployed website
- Verified using Public IP

## Technologies Used

- AWS EC2
- Ubuntu 22.04
- Nginx
- Linux
- SSH
